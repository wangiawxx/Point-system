台球会员积分排行榜系统


一、项目目标

为台球厅提供一个简单的会员积分管理和排行榜展示系统。

系统包含两个部分：
1. 用户端积分排行榜大屏，用于电视、电脑或公共屏幕展示。
2. 管理后台，用于用户管理、积分录入、排行查看和基础数据统计。

第一版不实现自动开台计时、收银系统对接、微信登录、积分兑换、多门店等扩展功能。

二、角色说明

1. 公共大屏用户

公共大屏不需要登录，只能查看积分排行榜，不能进入管理后台。

2. 管理员

管理员登录后台后，可以管理用户和积分数据，并查看统计信息。

三、用户端大屏

访问地址：/#/screen

功能要求：
1. 全屏展示会员积分排行榜。
2. 使用台球桌背景图，整体风格参考提供的设计图。
3. 显示金色标题“会员积分排行榜”。
4. 显示副标题“玩球一分钟，累计一积分”。
5. 显示“实时更新”标识。
6. 排行榜按积分从高到低排序。
7. 显示排名、会员昵称、累计积分、今日时长。
8. 手机号不在公共大屏显示完整信息。
9. 不显示后台入口和返回后台按钮。
10. 管理后台点击“打开大屏”时，在新窗口打开独立大屏页面。

四、管理后台

后台页面使用独立路由，每个功能对应一个单独页面。

1. 后台概览

访问地址：/#/admin/dashboard

显示内容：
- 会员总数
- 积分总量
- 今日新增积分
- 本月活跃会员数
- 积分增长趋势图
- 当前积分 TOP 5 排行

2. 用户管理

访问地址：/#/admin/users

功能要求：
- 查看用户列表
- 新增用户
- 编辑用户信息（后续补充）
- 按手机号尾号搜索
- 查看用户当前积分
- 跳转到积分录入页面

用户字段：
- 用户 ID
- 用户昵称
- 手机号
- 当前积分
- 加入时间
- 状态
- 备注（可选）

3. 积分录入

访问地址：/#/admin/points

功能要求：
- 搜索并选择用户
- 输入增加积分数量
- 支持输入扣减积分数量
- 填写积分变动备注
- 保存积分变动
- 保存后更新用户当前积分
- 保存后生成积分流水记录

积分录入规则：
- 增加积分为正数
- 扣减积分为负数
- 每一次积分变化都必须保留流水记录
- 流水记录包含变动前积分、变动积分、变动后积分、备注、操作时间

4. 后台积分排行

访问地址：/#/admin/ranking

功能要求：
- 查看总积分排行
- 查看本月积分排行
- 查看本周积分排行
- 显示排名、用户、手机号、积分和积分占比
- 按积分从高到低排序

五、后端接口

后端地址：默认 http://localhost:3000

管理员登录：
POST /auth/login

用户接口：
GET  /users
POST /users
GET  /users/:id

积分接口：
POST /points
GET  /points/records

排行和统计接口：
GET /ranking
GET /ranking/statistics

六、数据库设计

数据库使用 SQLite，数据库文件为 server/prisma/data/app.db。

1. admins 管理员表

- id
- username
- password
- createdAt

2. users 用户表

- id
- name
- phone
- points
- status
- joinedAt

3. point_records 积分流水表

- id
- userId
- amount
- before
- after
- note
- createdAt

积分流水表是积分变动的原始记录，用户当前积分是统计结果。

七、技术方案

前端：
- Vue 3
- Vue Router
- TypeScript/JavaScript
- 自定义响应式样式

后端：
- NestJS
- Prisma ORM
- SQLite
- REST API
- class-validator 参数校验

八、第一版验收标准

1. 管理员可以登录后台。
2. 管理员可以新增用户。
3. 管理员可以按昵称或手机号尾号搜索用户。
4. 管理员可以给用户增加或扣减积分。
5. 每次积分变化都有积分流水记录。
6. 后台可以查看积分排行。
7. 后台可以查看基础统计图表。
8. 用户端可以打开独立排行榜大屏。
9. 大屏使用台球背景图并展示金色排行榜样式。
10. 大屏无法返回或进入后台。
11. SQLite 数据库可以直接复制备份和迁移。
